# Tactic Sans (франшизный display-шрифт)

Tactic Sans — коммерческий шрифт Miller Type Foundry (Richard Miller).

## Что лежит здесь

| Файл | Вес | Использование |
|---|---|---|
| `tactic-sans-medium.woff2` | 400–699 (Medium, ~15 КБ) | обычные display-тексты |
| `tactic-sans-bold.woff2` | 700–900 (Bold, ~15 КБ) | **все заголовки сайта** (font-bold/extrabold/black маппятся на Bold — самое тяжёлое доступное начертание) |

Файлы — woff2-сабсеты под кириллицу + латиницу + пунктуацию сайта
(сгенерированы из исходников TTF; исходники хранятся в `fonts-source/`).

## Примечания

- `@font-face` прописан в `src/index.css` (два face по диапазонам весов,
  `local()`-подхват для машин, где семейство установлено).
- В Tactic Sans нет глифа «₽» — для него браузер корректно подставляет
  Montserrat (это нормальное поведение, визуально неотличимо).
- Если франшиза даст **ExtraBold (800)** или **Black (900)**: положите
  woff2 в эту папку и добавьте третий `@font-face` в `src/index.css`
  (диапазон 900 900), hero станет ещё тяжелее.
- Лицензия должна покрывать веб-публикацию (webfont) — это на стороне франшизы.
