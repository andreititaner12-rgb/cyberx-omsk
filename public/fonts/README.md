# Шрифт Tactic Sans (франшизный display-шрифт)

Tactic Sans — коммерческий шрифт Miller Type Foundry (Richard Miller).
Файлы дистрибуции в репозиторий **не включаются** — лицензию обеспечивает
франшиза CyberX.

## Как подключить

1. Положите лицензионные файлы webfont в эту папку:
   - `tactic-sans.woff2` — основной файл (можно склеить начертания 400–900
     одним variable-файлом, либо используйте Bold/Black для заголовков).
2. Готово: `@font-face` уже прописан в `src/index.css`
   (источники `local('Tactic Sans')` + `url('/fonts/tactic-sans.woff2')`).

До момента, пока файл отсутствует, все display-заголовки корректно
отрисовываются на **Montserrat 800/900** (тот же стилистический регистр) —
сайт полностью работоспособен и без Tactic Sans.

## Начертания, используемые сайтом

- 700 (Bold) — заголовки h3, карточки
- 800 (ExtraBold) — крупные цифры и мета
- 900 (Black) — hero, секционные заголовки, вордмарк
