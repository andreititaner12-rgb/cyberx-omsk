05 // Функционал

Что внутри сайта

01
Интерактивный прайс

Три клуба, 12+ тарифов, фильтр времени (утро/ночь). Выходные цены — красным, выбор клуба — свайп-табы.

02
КАРТА ОМСКА · УЛ. ЛЕНИНА, 19 МАРШРУТ В 2ГИС
Карта без API-ключей

Тёмные тайлы CARTO с фолбэками Esri → OSM, три метки клубов, перелёты, кнопка маршрута в 2ГИС.

03
Бронирование

Модалка: клуб → зона → время. Langame-ссылки каждого клуба, App Store, QR для админа клуба.

04
Раздел «Железо»

3D-макеты мышей (three.js, ленивая загрузка), бенчмарки ПК, тесты клавиатуры и мыши, симулятор плавности 600Hz.

05
Звуковой дизайн

Синтезированные UI-звуки (Web Audio): клики, ховеры, прелоадер. Mute-кнопка в шапке, без внешних файлов.

06
CS2-прицел и детали

Тактический курсор-прицел, blur-шапка, smart-pause видео hero, галереи клубов, прелоадер с телеметрией.

1
Владелец редактирует

Hero-тексты, клубы и фото (загрузка прямо из кабинета), зоны, весь прайс, турнир с датой, акции с промокодами, ссылки на соцсети и бронирование. вход: #admin?key=… + PIN

2
«Опубликовать»

Контент уходит на CMS-сервер одним запросом (JSON). Черновик — локально, для пробы. Экспорт/импорт JSON — резервная копия. PUT /api/content · x-cyberx-key

3
Все посетители видят сразу

Сайт при загрузке подтягивает актуальный контент с сервера. Никакой пересборки и перезаливки сайта на домен — только деплой CMS один раз. GET /api/content

07 // Технологии и деплой

Стек и запуск

Стек фронтенда

React 18 TypeScript строгий Vite 6 Tailwind 3.4 Framer Motion Lenis smooth-scroll Leaflet карты Three.js 3D qrcode

Стек CMS-сервера (папка server/)

Node.js Express CORS Multer загрузка фото data.json · атомарная запись

Запуск сайта

  1. Ставим зависимости: npm install
  2. Собираем: npm run build
  3. Содержимое dist/ — на веб-корень сервера (или любой статический хостинг)
  4. Опционально: деплой server/ на Render/Railway — 10 минут, инструкция в server/README.md
  5. Адрес CMS в src/config.ts → пересборка → «Опубликовать» в кабинете работает для всех
